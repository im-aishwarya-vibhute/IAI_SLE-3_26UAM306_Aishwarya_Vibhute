# SLE-3: Architectural Design using Full C4 Model

## Course

02AML204 – Introduction to Artificial Intelligence

## Project

Graph Search System using BFS and DFS

## Objective

The objective of this SLE-3 project is to represent the BFS and DFS Graph Search System using all four levels of the C4 model.

## C4 Model Levels

### Level 1 — Context

Shows the user and the Graph Search System.

### Level 2 — Container

Shows the main modules:

* Input Module
* Search Engine
* Visited Set
* Path Manager
* Output Module

### Level 3 — Component

Shows the internal components of the Search Engine:

* BFS Module
* DFS Module
* Goal Test
* Path Reconstructor

### Level 4 — Code

Shows the main functions used in the system:

* `bfs()`
* `dfs()`
* `timeit`
* Node counting
